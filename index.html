🚫 Как обходить CIDR и SNI блокировки

📍 CIDR-блокировка (по IP-адресам)

Как блокируют:

Роскомнадзор добавляет целые диапазоны IP-адресов в реестр блокировок. Трафик на эти IP обрывается провайдером.

Как обходим:

В конфигах используются white CIDR-списки — разрешённые («чистые») диапазоны IP. VPN направляет трафик только через эти белые подсети, обходя заблокированные адреса.

---

🔠 SNI-блокировка (по имени сервера)

Как блокируют:

Провайдер видит SNI (Server Name Indication) — имя сайта в открытом виде при подключении (например, youtube.com). Если имя в чёрном списке — соединение разрывается.

Как обходим:

Используются white SNI-списки и технологии Reality / uTLS. Они маскируют настоящее имя сайта или подменяют его на «чистое», чтобы провайдер не мог определить цель.

> 💡 Простыми словами:

> - CIDR — блокировка по «адресу дома»

> - SNI — блокировка по «названию на табличке»

> - White-списки позволяют обходить обе блокировки, направляя трафик через разрешённые IP и домены.

🆕 Что нового в V1.1
  • Управление профилями — сохраняйте, редактируйте и переключайтесь между профилями (хранятся в браузере).
  • Импорт профилей — вставьте ссылки на подписки, каждая превращается в отдельный редактируемый профиль.
  • Пользовательские поля — fingerprint, ALPN, VLESS flow/encryption и метод Shadowsocks теперь поддерживают произвольные значения "Custom…".
  • Allow Insecure — переключатель для самоподписанных сертификатов.
  • Гибкий выбор портов — предустановленные порты + пользовательские (можно удалять).
  • Умное именование — три стиля: простые номера, эмодзи или флаг/код страны — с предпросмотром.
  • Улучшенная обработка IPv6 — адреса автоматически форматируются для ссылок.
  • QR-код в результатах пинга — сканируйте прямо из таблицы задержек.
  • Тёмная / светлая тема — переключайте кнопкой, настройки сохраняются.
✨ Основные возможности
  • Импорт ссылок (vless://, vmess://, trojan://, ss://) — автоматическое заполнение всех настроек.
  • Полная поддержка транспортов: TCP, WebSocket, gRPC, HTTP/2, mKCP, QUIC, HTTP Upgrade, SplitHTTP, XHTTP.
  • Безопасность TLS и Reality — с SNI, fingerprint, ALPN, публичным ключом, short ID и Spider X.
  • Пакетная генерация — вставьте список IP/доменов (IPv4/IPv6) и получите конфиги для всех выбранных портов.
  • Двойной вывод: полный JSON (Xray/V2Ray или Sing‑box) или ссылки для шаринга.
  • Пинг-тест (только WebSocket) — измеряет задержку, сортирует результаты, копирует ссылки и показывает QR.
  • Экспорт подписки в Base64 — готово для импорта в любой клиент.
  • Копирование и скачивание отдельных конфигов или всего пакета.
🚀 Быстрый старт
  1. Вставьте ссылки на подписки в верхнее поле и нажмите "Import as Profiles".
  2. Выберите профиль из таблицы — его настройки загрузятся в форму.
  3. Настройте Core (Xray / V2Ray / Sing‑box), протокол, сеть, безопасность и другие параметры.
  4. Выберите один или несколько портов, нажимая на них (при необходимости добавьте пользовательские).
  5. Введите IP-адреса или домены в поле "IP / Domain List" (по одному на строку, поддерживается IPv6).
  6. Нажмите "Generate Configs".
  7. Переключайтесь между вкладками JSON и Links для просмотра результатов.
  8. Используйте кнопки Copy, Download, Ping или QR по необходимости.
⚠️ Важное примечание

Функция Ping надёжно работает только для транспорта WebSocket. Для других транспортов будет отображаться "N/A". Вы можете продолжить, подтвердив предупреждение.
